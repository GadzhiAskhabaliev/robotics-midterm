# Parallel Gripper

Native SOLIDWORKS parallel gripper (gear-driven parallelogram jaws).

## Motion

Open ↔ close animation: [`GripperGif.mp4`](GripperGif.mp4)

## SolidWorks

Open `Assem1.SLDASM` together with the `PG_*.SLDPRT` files in this folder (do not rename the parts).

Per-part STEP geometry is also here (`01_…`–`12_…`, matching the assembly).

## Files

| File | Role |
|------|------|
| `Assem1.SLDASM` | Assembly with mates |
| `PG_*.SLDPRT` | Native parts |
| `*.step` | Source geometry for the parts |
| `GripperGif.mp4` | Jaw open–close animation |
