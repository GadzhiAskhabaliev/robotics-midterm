How to show motion in SolidWorks
  1. Open solidworks/Assem1.SLDASM (keep all PG_*.SLDPRT beside it).
  2. Configuration Manager → Open / Half / Grip_62mm (if present), or
  3. Macro → Run macros/Demo_OpenClose_Live.swb, or
  4. Drag drive gear if mates allow DOF.
